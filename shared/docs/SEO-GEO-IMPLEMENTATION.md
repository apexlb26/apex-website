# APEX SEO + GEO implementation

This implementation deliberately keeps GEO on top of standard technical SEO instead of adding a separate framework.

Implemented:

- canonical metadata on every public route
- route-specific titles and descriptions
- Open Graph and Twitter metadata
- large image/snippet preview directives for Googlebot
- `robots.txt` with public crawl access and explicit `OAI-SearchBot` access
- sitemap covering every public route
- global Organization, WebSite, Service, and OfferCatalog JSON-LD
- route-level WebPage/CollectionPage and BreadcrumbList JSON-LD
- consistent service and industry entities in structured data
- Products, Blogs, and Careers moved to their own public pages from the home page

Important: GEO does not need a special schema or third-party library. Keep content public, crawlable, specific, factual, and consistent. Case studies, visible service descriptions, clear headings, dates/authors on real articles, and internal links are more useful than hidden AI-only text.
